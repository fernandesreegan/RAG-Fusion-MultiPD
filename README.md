# Multi-PDF RAG with Sources

A Streamlit application using LangChain, OpenAI embeddings, FAISS, and page-aware PDF citations.

## Setup (Windows)

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

Edit `.env` and add your OpenAI API key. Do not commit `.env`.

```powershell
streamlit run app.py
```

Upload the three sample PDFs (or your own text-based PDFs), select **Process PDFs**, then ask a question.

## Suggested questions

1. What are the SQL Server backup and recovery targets?
2. How does MariaDB indexing help assignedTo and visibility queries?
3. Compare the recovery objectives across SQL Server, MariaDB, and PostgreSQL. Are they identical?
4. What is the official company-wide backup policy? (Not specified in these sample PDFs.)

## How it works

PDF pages -> text chunks with filename/page metadata -> OpenAI embeddings -> FAISS -> top matching excerpts -> OpenAI answer with source IDs -> expandable evidence.

## Notes

- Page numbers are converted from zero-based PDF metadata to human-readable 1-based page numbers.
- Different documents may describe different service policies, which should be reported separately.
- Source citations are generated by the model from the supplied retrieved excerpts; verify important claims against the shown excerpts.
- For very large PDFs, consider persistent vector storage and more selective retrieval.
- Sample PDFs contain fictional training guidance, not production policy.
